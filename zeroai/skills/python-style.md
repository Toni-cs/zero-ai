# Python 编码规范（zero-ai 项目）

## 硬性要求

1. **注释与文档字符串用中文**，与项目既有代码一致。
2. **遵循 PEP 8**；列宽以既有文件为准，不要中途改风格。
3. **修改核心文件前先备份**，备份目录见仓库 `.backup_*`。
4. **编辑含非 ASCII 的文件前先做编码体检** —— 编辑工具曾把 `.gitignore`
   写坏过一次，`.gitignore` 已加编码守卫测试。

## 失败处理

- **不要写裸 `except: pass`**。吞掉异常至少要写清楚"为什么这里可以忽略"。
- 项目里已知有 8 处 `except: pass`（`ssh_ops`），属于待清理项，别扩散。
- 可能失败的外部调用，返回**三态**（成功 / 明确失败 / 无法判断），
  不要把"查不到"和"不存在"混成一个结果。

## 命名

- 模块级函数用 `动词_名词`：`format_file`、`discover_skills`
- 常量全大写：`BUILTIN_FORMATTERS`
- 私有实现前缀 `_`，但**测试要能测到**——用下划线不等于藏起来

## PowerShell 环境注意

- 中文输出会乱码，结论尽量落文件再读
- `||` 在 PowerShell 中不可用，用独立语句
- `python -c` 写多行会引号冲突，**落成 .py 文件再执行**
